# Triplopia Simulator

Upload a photo and see a GPU (WebGL2) simulation of monocular triple vision caused by an irregular cornea.
Three fixed, slightly offset copies of the image compete for dominance in a continuous, milky crossfade.
Everything runs in your browser; images never leave your device.

Live: https://who.github.io/triplopia/

See [PRD.md](PRD.md) for the design and the model behind it.
